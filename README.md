# Adam & Chriss — Cloud Barber (Cairo)

Elite, booking-only mobile barbering service. The website is the business hub; WhatsApp is the front door; Arabic chat is the owner's operating system.

- **Live:** [adamandchriss.com](https://adamandchriss.com)
- **Docs:** [PRD](docs/PRD.md) · [Terms](docs/Terms.md) · [Phases](docs/Phases.md)

## Quick start

```bash
pnpm install
pnpm dev
# → http://localhost:3000
```
